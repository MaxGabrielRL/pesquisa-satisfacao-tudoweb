# Pesquisa de Satisfação - Tudo Web

Programa desenvolvido para atividade da disciplina de Desenvolvimento de Sistemas.

## Objetivo

Criação de um programa em Python para realizar uma pesquisa de satisfação dos clientes com o atendimento da TudoWeb.

O programa solicita os dados: Nome, idade e a opinião do cliente sobre o atendimento. As opções de opinião para o cliente são:
1 - EXCELENTE
2 - BOM
3 - RUIM

Após concluir a coleta de dados das opiniões dos clientes o programa exibirá a quantidade de respostas EXCELENTE e RUIM.

Os prints do código e execução estão na pasta prints.

Código para execução do programa:
```bash
python pesquisa_satisfacao.py
